A 100-word monologue for a fantasy villain who is secretly just very tired — an innkeeper who has heard every murder plot whispered over his stew for twenty years, and survives by forgetting them. Entry for the [make.fun bounty](https://make.fun/bounty/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb).

## How it works

`main.ts` (Node 22, stdlib-only, no network) writes the monologue to `/output/entry.txt` — 99 words, 529 characters, deterministic across runs.

```sh
node main.ts
cat /output/entry.txt
```
